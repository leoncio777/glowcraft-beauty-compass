# Glowcraft Beauty Compass - Beauty AI Studio

Aplicativo inteligente de consultoria de beleza com IA, análise facial e capilar, catálogo de cosméticos e planos comerciais.

## Tecnologias
- React 19 + TypeScript
- TanStack Start / Router / Query
- Tailwind CSS
- Supabase / Lovable Cloud (PostgreSQL, Auth, Storage)
- Lovable AI Gateway
